# payflow
O PayFlow é uma plataforma de cobranças e pagamentos para pequenos negócios (um Asaas/PagSeguro simplificado)

O lojista cria cobranças (Pix, boleto e cartão simulados), recebe pagamentos numa
carteira controlada por um ledger, é avisado por webhooks e acompanha tudo num painel
React. Ao longo do caminho entram antifraude, conciliação em batch, integração com um
banco parceiro instável, observabilidade e IA
